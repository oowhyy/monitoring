# 🚀 Быстрый старт

Это краткое руководство для быстрого запуска системы мониторинга логов.

## Предварительные требования

✅ Docker и Docker Compose установлены  
✅ Порты 3000 и 3100 свободны  
✅ Минимум 2GB RAM  

## 3 шага до запуска

### 1️⃣ Подготовка

```bash
# Перейдите в директорию проекта
cd /path/to/monitoring

# Создайте необходимые директории и файлы
make setup
```

### 2️⃣ Запуск

```bash
# Запустите все сервисы
make start

# Или без Makefile:
docker-compose up -d
```

### 3️⃣ Проверка

```bash
# Создайте тестовые логи
make test-logs

# Или запустите демо приложение
cd go-demo
go run main.go > ../logs/app.log 2>&1 &
cd ..
```

## Откройте Grafana

1. Перейдите на http://localhost:3000
2. Войдите:
   - **Логин**: admin
   - **Пароль**: admin
3. Перейдите в **Dashboards → Logs → Go Application Logs**
4. Через несколько секунд увидите тестовые логи! 🎉

## Что дальше?

Настройте ваше приложение для записи JSON логов в stdout и перенаправьте в файл:

```bash
# Ваше приложение пишет в stdout, вы перенаправляете в файл
./your-app > logs/app.log 2>&1 &

# Или для Go приложения
cd go-demo
go run main.go > ../logs/app.log 2>&1 &

# Promtail автоматически подхватит логи из logs/*.log
```

## Полезные команды

```bash
make help        # Показать все доступные команды
make status      # Проверить статус сервисов
make logs        # Смотреть логи в реальном времени
make stop        # Остановить сервисы
make restart     # Перезапустить сервисы
```

## Кастомизация

Отредактируйте `.env` файл для изменения:
- Портов
- Путей к данным
- Источников логов
- Учетных данных

```bash
nano .env
# Измените параметры
make restart
```
